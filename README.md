# MineOS CC — порт для CC:Tweaked

Адаптация MineOS для OpenComputers под **CC:Tweaked в Minecraft 1.20.1**.

В этом репозитории находятся CC:Tweaked-адаптер, патчи и установщик. Чтобы не дублировать оригинальный проект, установщик загружает исходники MineOS из зафиксированного upstream-коммита f47c7fc (https://github.com/IgorTimofeev/MineOS/commit/f47c7fcf29e65f0ac27363dde3f79dae7c24395b), после чего накладывает адаптацию из этого репозитория.

## Установка на компьютер CC:Tweaked

1. В настройках CC:Tweaked включи HTTP API и разреши доступ к api.github.com и raw.githubusercontent.com.
2. На компьютере выполни:

   wget https://raw.githubusercontent.com/Frez7373/MineOS/main/cc-tweaked/install.lua install.lua
   install.lua

3. Подтверди установку клавишей Y. После окончания можно перезагрузить компьютер.

Установщик загружает оригинальные файлы MineOS, сохраняет перезаписываемые файлы в /MineOS-CC-backup-*, устанавливает CC:Tweaked-загрузчик и применяет патчи для изменения размера экрана и русского языка профиля по умолчанию.

## Возможности адаптера

- встроенный терминал CC:Tweaked или подключённый цветной монитор;
- преобразование графики MineOS в 16-цветную палитру CC:Tweaked;
- файловая система CC:Tweaked;
- клавиатура, мышь и касания монитора;
- HTTP и Rednet через API CC:Tweaked;
- UTF-8 и поддержка русского текста;
- тёмная тема и русский язык профиля по умолчанию.

## Требования и ограничения

- Minecraft 1.20.1 и совместимая версия CC:Tweaked;
- включённый HTTP API и доступ к GitHub при установке;
- около 2.5 MiB свободного места под MineOS, плюс место для резервной копии существующих файлов.

Приложения, которым нужны роботы, принтеры, 3D-ускорители или другие устройства OpenComputers, не становятся автоматически совместимыми с CC:Tweaked.
